# Créditos e atribuições

Este projeto é uma **cópia independente** (não é um *fork*), reescrita para uso
próprio do gabinete, com melhorias e uma camada penal editável. Ele se apoia,
direta ou indiretamente, no trabalho aberto de:

- **TecJustiça Transcribe** — Marcos (`marcosmarf27`). Ideia de referência de um
  transcritor de audiências com WhisperX + diarização, distribuído como software
  livre sob **licença MIT**. Repositórios:
  [CLI](https://github.com/marcosmarf27/tecjustica-transcribe-cli) ·
  [desktop](https://github.com/marcosmarf27/tecjustica-transcribe-desktop-releases).
- **WhisperX** — Max Bain et al. (BSD/MIT). Alinhamento e diarização sobre Whisper.
- **OpenAI Whisper** — modelo de ASR multilíngue (MIT).
- **pyannote.audio** — diarização de falantes (MIT).
- **NVIDIA Parakeet** — alternativa de motor rápido em CPU (CC-BY-4.0), citada no plano.

Agradecimento especial ao autor do TecJustiça por abrir o código para a
comunidade jurídica. Se este projeto reaproveitar trechos de código do TecJustiça,
o aviso de copyright MIT correspondente será mantido nos arquivos afetados.
